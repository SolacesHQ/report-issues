## How to Raise an Issue

1. **Sign in to GitHub**
   - You must be signed in to your GitHub account to create an issue.

2. **Go to the Issues Tab**
   - Click on the `Issues` tab at the top of this repository.

3. **Click `New Issue`**
   - Select the appropriate issue template (Bug, Feature Request, or General Inquiry).

4. **Fill Out the Template**
   - Provide all required information. The more details you provide, the faster we can help!

5. **Submit the Issue**
   - Click `Submit new issue` to create your issue.

## Issue Templates

We provide the following templates to streamline the process:

### 1. Bug Report
- **Title:** Clear and concise summary of the bug
- **Description:** Detailed explanation of the issue
- **Steps to Reproduce:** List the steps to reproduce the bug
- **Expected Behavior:** What you expected to happen
- **Actual Behavior:** What actually happened
- **Screenshots/Logs:** Attach if available
- **Environment:** Browser, OS, device, etc.

### 2. Feature Request
- **Title:** Short description of the feature
- **Description:** What is the feature and why is it needed?
- **Proposed Solution:** (Optional) How you think it could be implemented
- **Additional Context:** Any other information

### 3. General Inquiry
- **Title:** Brief summary
- **Description:** Your question or comment

## Best Practices
- **Search First:** Please check existing issues before creating a new one to avoid duplicates.
- **Be Clear:** Use descriptive titles and provide as much detail as possible.
- **Stay Respectful:** Follow the [Code of Conduct](LICENSE) and be respectful to maintainers and other users.

## What Happens Next?
- A maintainer will review your issue and may ask for additional information.
- You will be notified of updates via GitHub notifications.
- Issues will be labeled, prioritized, and assigned as appropriate.
